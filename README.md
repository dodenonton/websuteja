# Suteja Wood Art - Balinese Master Woodcarving & Art Gallery 🪵✨

Website profil bisnis, galeri seni, dan portofolio resmi untuk **Suteja Wood Art** yang berlokasi di **Desa Mas, Ubud, Gianyar, Bali**. 

Project ini dibuat terpisah secara mandiri di luar folder `dewa-bike-tour`, berbasis teknologi web modern murni (**HTML5, CSS3, dan Vanilla JavaScript**) yang ringan, responsif, berestetika mewah (*luxury dark wood & warm gold*), dan siap dihosting gratis selamanya di **GitHub Pages**, **Netlify**, atau **Vercel**.

## 🌟 Fitur & Keunggulan Desain

1. **Brand Identity Mewah & Autentik Bali**:
   - Palet warna hangat khas kayu eksotis (*ebony, warm mahogany, caramel, natural ivory, champagne gold*).
   - Tipografi elegan kombinasi *Cormorant Garamond* (huruf serif seni pahat) dan *Plus Jakarta Sans* (bacaan modern yang sangat bersih).
2. **Konektivitas WhatsApp Otomatis (Direct Order)**:
   - Tombol pada setiap item karya seni langsung membuat pesan WhatsApp terformat rapi berisi judul karya, material kayu, dimensi, dan pertanyaan ketersediaan.
   - Formulir **Custom Commission** di halaman kontak langsung mentransfer data nama, email, pilihan kayu, dimensi, dan konsep ukiran ke chat WhatsApp pengrajin.
3. **Filter Interaktif & Lightbox Modal**:
   - Di `gallery.html`, pengunjung dapat memfilter berdasarkan kategori: *Semua*, *Patung Mitologi*, *Topeng & Barong*, *Panel Relief 3D*, dan *Dekorasi Organik*.
   - Modal detail interaktif menampilkan spesifikasi kayu, estimasi waktu pengerjaan, dan estimasi harga dalam Rupiah & USD.
4. **Navigasi Multi-Level & Responsif Penuh**:
   - Menu dropdown desktop yang mulus.
   - Mobile menu toggle untuk kenyamanan akses dari smartphone & tablet.
5. **SEO & International Ready**:
   - Dilengkapi meta deskripsi, OpenGraph tags, serta panduan pengemasan kargo peti kayu berstandar ekspor fumigasi ISPM 15 untuk pembeli mancanegara.

## 🚀 Cara Menjalankan & Preview

### Opsi 1: Buka Langsung di Browser
Klik dua kali file `index.html` pada File Explorer / Finder untuk membuka langsung di Google Chrome, Safari, atau Firefox.

### Opsi 2: Menggunakan Local Server (Python / Node / VS Code Live Server)
Buka terminal di dalam folder project:
```bash
# Menggunakan Python:
python3 -m http.server 8080

# Lalu buka di browser:
http://localhost:8080
```
